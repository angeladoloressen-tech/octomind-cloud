# Critical Digital Synthesis — Start Here

**Art × AI × Legitimacy × Society**

Critical Digital Synthesis is an independent artist-research program examining how conversational AI, infrastructure and institutional rules become visible — or invisible — to the people affected by them.

## Distribution rule

A work is not finished when it is created. It is finished when it has:

1. a canonical home,
2. a discovery path,
3. an audience-capture path,
4. a legitimate route to value.
